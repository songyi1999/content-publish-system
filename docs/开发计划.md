## 开发规范

- **分支**：main 受保护；功能分支 `feat/m1-user-crud` 格式；PR 必须 CI 绿。
- **提交**：Conventional Commits（feat/fix/docs/chore/refactor/test）。
- **接口**：REST，路径 `/api/<资源>`；响应统一 `{ ok, data | message }`（见 shared ApiResult）；协议改动先改 `packages/shared`。
- **类型**：strict；禁止 any 提交（CI typecheck 拦截）。
- **测试**：player-core 纯逻辑必须有单测；服务端关键流程（auth、状态机、排期）补集成测试。
