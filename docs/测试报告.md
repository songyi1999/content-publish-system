- **真实视频转码（T3，ED-07）**：容器内 ffmpeg 生成 HEVC/AAC 测试视频上传，产物转码为 H.264/AAC + faststart（46559B→68769B），转码后 sha256 重算，终端下载校验一致。
- **100 终端压测（D8-A）**：模拟 100 台终端 WebSocket 心跳+清单轮询 60 秒，心跳连接 100/100、失败 0，清单时延 avg 434ms / p99 565ms，详见《压测报告.md》。
- **HTTPS 链路（D8-A）**：`https://IP:8443` 静态页 200、`/api/health` 200、登录 200、终端 WebSocket(/socket.io) 经 nginx 反代连接成功；APK 内置 CA（network_security_config），Electron 放行 CPS Root CA 签发证书。
- **管理端视觉验证**：节目编排（区域配置/模板列）、排期月视图、内容横竖屏预览弹窗均正常渲染。
- **签名验证**：v1.2.2 APK apksigner 校验通过（CN=CPS Player，与历史版本同证书，可覆盖安装）。
